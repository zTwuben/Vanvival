# Vanvival

Vanvival is a Project Zomboid mod that lets players begin the apocalypse with a vehicle and supplies, supporting a true nomadic survival playstyle.

## Features

- Spawn with a customizable starter vehicle.
- Multiple starting traits:
  - Van Survivor
  - RV Owner
  - Bike Owner
- Configurable through sandbox settings.
- Compatible with Build 42.

## Requirements

- Project Zomboid Build 42

## Installation

Subscribe on the Steam Workshop or install manually.

## Compatibility

Vanvival is designed to be compatible with most mods. If you encounter any conflicts, please open an issue on GitHub.
